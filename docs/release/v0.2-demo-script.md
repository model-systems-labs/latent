# Latent v0.2 short demo

Target length: 90 seconds.

Use these exact released commands:

```bash
git clone --depth 1 --branch course-kit-v0.2.0 \
  https://github.com/model-systems-labs/latent.git
cd latent
npm ci

npm run create:platform -- ../my-school \
  --title "My School" \
  --tagline "Learn one useful idea, retrieve it, and put it to work." \
  --accent "#7c3aed"

cd ../my-school
npm run validate
npm run build
npm run preview
```

1. Start from an empty directory and run the documented platform creation
   command.
2. Show the supplied platform name and brand color in the generated source
   tree.
3. Run the validation command and point out the four reported primitives:
   lesson, flash-card deck, Question Group, and browser IDE exercise.
4. Build the deterministic static output and start the local preview.
5. Open the lesson and move to its card deck.
6. Open programming practice, run the example case, then solve a check case.
7. Open the IDE exercise, change the trusted starter source, and run its
   host-owned checks.
8. Show the generated static output and the GitHub Pages workflow.
9. Close on the full LLM Learning reference application and its source
   repository.

The recording must use the exact released command and artifacts. Do not splice
in a development-only path or claim npm availability.
