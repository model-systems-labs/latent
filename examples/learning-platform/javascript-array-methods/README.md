# Array Method School

A tiny, dependency-free Latent platform showing a lesson, flash-card deck,
Question Group, and reviewed browser JavaScript exercise.

```bash
npm run validate
npm run preview
```

Node 22.13 or newer is the only prerequisite. Validation is offline and uses
the checked-in canonical Course Kit validator artifact. The preview command
validates, builds `dist/`, and serves that exact static artifact on loopback.

Read [GUIDE.md](./GUIDE.md) for the ten-minute project map and GitHub Pages
instructions. Read [AGENTS.md](./AGENTS.md) before asking a coding agent to
change the platform.
