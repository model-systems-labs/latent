# Ten Problems

Ten original Python interview-practice problems in one focused workspace.
Choose a problem, read the contract, write code, run the example, and check the
full visible case set. Progress stays on the learner's device.

```bash
npm run validate
npm run preview
```

The example intentionally uses one Latent primitive: a portable Question Group
library. There is no course, flash-card deck, feature tour, model call, account,
or application server. A reviewed host adapter runs submitted Python in a fresh
browser worker using the same-origin, version-pinned Pyodide runtime shipped by
the build. It does not send learner source to a server.
