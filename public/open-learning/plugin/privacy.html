Neural Chalk plugin privacy notice

Effective August 5, 2026

The Neural Chalk plugin is a skills-only package for Codex and Claude Code. Model Systems Labs does not operate an account, analytics, telemetry, or data-processing service for the plugin.

Local files and agent hosts

The plugin instructs the installed coding agent to read sources the user places in scope, edit learning-project files, and run the released Course Kit command-line tool. Those operations occur under the agent host's sandbox, approval, authentication, logging, and data-use settings. Do not place secrets or unnecessary personal information in course sources or generated content.

Network requests

Course Kit installation can download the immutable Neural Chalk release artifact from GitHub and its pinned dependencies from the configured npm registry. Source review can open user-authorized links. Publishing and remote verification contact only the destination or feed the user identifies. GitHub, npm, the coding-agent provider, source publishers, and deployment providers process requests under their own notices.

Published learning material

Learning Packs and Question Groups are files controlled by their publisher. The plugin does not upload them to Model Systems Labs. A user who deploys generated files chooses the host and is responsible for the privacy notice, access controls, retention, and content appropriate to that deployment.

Contact

Ask general questions through the public issue tracker without posting private information. Report suspected security or privacy vulnerabilities through the private vulnerability form.
