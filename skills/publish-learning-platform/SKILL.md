# Publish Learning Platform

Publish the exact reviewed commit and generated bytes. Do not edit learning
content during a release pass.

## Establish the target

Read the platform's `AGENTS.md`, `GUIDE.md`, deployment workflow, and current
release status. Resolve the source commit, intended host, access level, and
whether the user authorized external deployment.

Keep claims separate:

- validation proves format and automated contracts;
- review records learning-quality evidence;
- deployment proves a host accepted bytes;
- certification requires a separate explicit attestation.

## Run the gate

From the platform root:

```bash
npm run validate
npm run build
```

Build a second time in a fresh checkout or directory and compare the complete
artifact. Stop on any diff, warning, uncommitted source change, placeholder,
unlicensed content, or mismatched release identity.

Preview the exact build. Exercise all four primitives, failure feedback,
keyboard navigation, mobile layout, reload persistence, source links, and the
leech-only progress query. Record any browser check that could not be run.
If the reviewed platform contains trusted interactives, also exercise every
advertised path, exact-state reload, host reset, capability failure, and
completion evidence at desktop and compact widths. Confirm the generated
artifact contains the reviewed source rather than fetching executable bytes.

## Publish by layer

Deploy only the generated static directory. Do not publish source files,
credentials, caches, or a different commit. For GitHub Pages, use the
checked-in workflow and verify the workflow's artifact points to `dist/`.

After deployment, verify the live route and immutable content URLs, then
compare representative live bytes with the local artifact. Never silently
overwrite an already-published immutable content identity.

## Handoff

Report the exact commit, validation and independent-review status, local build,
deployed URL, host access level, live verification, and unresolved checks.
Do not claim a tag, release, central submission, or public deployment unless
that external action actually succeeded.
